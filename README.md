# Revora.ai

Revora.ai is an AI-powered academic support system that helps students revise more effectively using their own study materials.

## About

The system allows users to upload notes, slides, PDFs, and past question papers, then turns them into grounded revision support through AI-generated answers, likely question insights, personalized quizzes, voice interaction, timed mock tests, and basic proctoring.

## Goal

The main goal of Revora.ai is to make revision more organized, interactive, and useful by turning student-owned materials into meaningful practice and feedback.
